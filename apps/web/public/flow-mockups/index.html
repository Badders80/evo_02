Horizontal Fallbacks per Step

2 Step 2 — Term Sheet

Stake validation error (over/under/non-multiple/empty) Terms not accepted → CTA disabled ← Back to horse page

3 Step 3 — SA Acceptance

SA not accepted → CTA disabled API error → toast + stay on step KYC redirect fail → retry KYC ← Back to Step 2

4 Step 4 — KYC

KYC verified → auto-advance KYC pending → poll / check again KYC rejected → support / retry Redirect fail → manual link ← Back to Step 3

5 Step 5 — Checkout

Payment success → webhook → holding Card declined → retry / different card User cancelled → retry (15 min hold) Stripe error → toast + retry Network timeout → idempotency key ← Back to KYC

6 Step 6 — Holding

Holding created → MyStable DB error → alert ops + support Duplicate webhook → idempotent Reservation expired → refund ← Back to Checkout
